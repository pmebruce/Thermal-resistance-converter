# 熱阻換算器

工程用 PWA，協助在熱傳導係數、厚度、面積熱阻與總熱阻之間快速換算。

## 功能

- k → 面積熱阻 R″
- 面積熱阻 R″ → 等效 k
- 指定面積後換算總熱阻 K/W
- 指定熱量後估算材料溫差
- 多層材料串聯與熱阻占比
- SI／英制常用單位轉換
- DIV-300 與 DM-800A 快速範例
- 可安裝並離線使用

## 主要關係式

R″ = t / k

R = R″ / A

ΔT = Q × R

多層串聯：R″total = Σ(tᵢ / kᵢ)

## Darbond 預設值

| 材料 | 建模厚度 | TDS 標示 k | TDS 面積熱阻與條件 | 反算等效 k |
| --- | ---: | ---: | ---: | ---: |
| DIV-300 | 0.20 mm | 15.0 W/m·K | 0.050 °C·in²/W @ 50 psi | 6.2000 W/m·K |
| DM-800A | 0.05 mm | 8.0 W/m·K | 0.006 °C·in²/W @ 80 °C、40 psi | 12.9167 W/m·K |

反算等效 k 用於讓指定厚度的 FloTHERM XT 實體模型重現 TDS 面積熱阻，並不等於材料的本體 k。若採用這組等效值，不應再重複加入相同的接觸熱阻。DM-800A 的 0.05 mm 是指定建模厚度；原 TDS 圖片列出的供應厚度範圍為 0.1–0.3 mm，因此這個等效值應視為校準用輸入。
